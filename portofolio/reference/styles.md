# Style Guide — Gracia G Logo Brand

## Fonts
- Headings: Fraunces, 700 weight
- Body: Inter, 400 weight (600 for bold/emphasis)
- Google Fonts: https://fonts.google.com/specimen/Fraunces | https://fonts.google.com/specimen/Inter

## Type Sizes
- H1: 40px / Fraunces 700
- H2: 28px / Fraunces 700
- H3: 20px / Fraunces 600
- Body: 16px / Inter 400
- Small label / caption: 13px / Inter 400 (uppercase optional, add slight letter-spacing if so)

## Colors
- Text: `#1C2B27`
- Background: `#FFFFF0`
- Primary (buttons, headlines, key UI): `#2B6E5B`
- Link / small text accent: `#2F7A56` (use this, not the light mint, for anything readable)
- Accent — large surfaces only (icons, big buttons, borders, backgrounds): `#7FC49E`

## Spacing
- Base unit: 8px. All margins/padding are multiples of it (8, 16, 24, 32...)
- Section padding (top/bottom): 64px desktop, 32px mobile
- Space between heading and body text: 16px
- Space between unrelated blocks/sections: 48–64px
- Line height: 1.2 for headings, 1.5 for body
